# Windows 桌面外壳

外壳使用 .NET 8 Windows Desktop 和 WebView2，承载本机后端的设置向导与工作台。
当前源码可以编译；编译成功不代表目标机器运行时、安装器或完整模型链已经验收。

开发构建（需预先准备项目依赖）：
```
dotnet build desktop/win11/SemanticCamera.Desktop.csproj -c Release \
  -p:Version=<pyproject.toml project.version>
```
运行约定：
- 唯一用户入口 `语义摄像头.exe`，内部后端 `backend\semantic-camera-backend.exe`；
- 壳↔后端 stdio JSONL v1（Python 侧实现在 `scam/win11_desktop.py`）；
- 仅允许后端登记的 `127.0.0.1` origin；外部 https 仅用户显式点击后交系统浏览器；
- 关闭询问（继续值守/停止并退出/取消）、托盘恢复、正常停止握手、超时保持窗口。

## 配置有误时恢复

托盘菜单“新建替代配置（仅本次）”会先请求后台正常停止；停止未完成时不启动
第二个后台，也不强制结束原进程。向导成功保存后，在原配置同目录创建一个独立
替代文件，仅用于本次后台运行。取消或保存失败不会覆盖原配置。

重新启动应用仍使用原配置；此功能不自动把替代文件设为默认。若要后续显式使用
已有替代文件，可通过支持外置配置的启动脚本传入该文件。请勿把含摄像头地址或
凭据的配置放进程序发布目录或转发给他人。

后端开发入口支持显式 `--desktop --recover-config --config <原配置绝对路径>`。
此开关只启动替代配置向导，不接受任意系统命令。外壳仅转发固定白名单参数。

配置诊断命令与恢复功能在不同构建中可能尚未同时封装；使用时应以该候选附带的
说明和实际验收记录为准，不把当前源码功能等同于任意旧安装包已支持。
