# Windows 开发版使用说明

本说明适用于 Windows 桌面开发版。开发版用于本机验证，尚不代表正式发布或语义识别质量已达标；请勿将模型描述直接作为确定事实或唯一告警依据。

## 选择正确的安装包

面向正常用户的安装包与标有 Test 的隔离测试安装包使用不同的应用身份和目录。测试包用于安装维护验证，不应替代正式产品包，也不能用其测试结果推断正式包已验收。请核对提供方给出的包名、版本、SHA-256 和适用说明。

TestMode 不会自动改变应用运行时的用户数据根；测试启动仍须显式使用独立配置和数据路径，避免与日常配置混用。

若文件没有数字签名，Windows 可能显示未知发布者或安全提示。未签名不等于文件已被证明安全；仅在确认来源可信、摘要一致且理解开发版风险后使用，不要关闭系统安全保护来强行运行。来源或摘要不符时停止安装。

## 首次启动

正常安装默认仅面向当前用户。桌面程序需要可用的 .NET 8 Desktop Runtime 和 WebView2 Runtime；具体包是否自带运行时，以随包说明为准。缺少运行时时，只从官方来源获取所需组件。

首次启动按向导填写摄像头地址和接入信息。确认画面在线后再检查各层能力状态；画面可见不代表对象检测、关系分析或图片理解均已启用。图片理解可以保持关闭；启用本地模型前需确认模型文件、依赖和内存可用。

## 本机数据与备份

正常用户数据默认位于 `%LOCALAPPDATA%\semantic-camera`，配置通常为该目录中的 `cameras.json`。程序文件默认位于 `%LOCALAPPDATA%\Programs\SemanticCamera`。配置或启动参数指定了其他位置时，以实际路径为准；录像、证据与模型可能使用单独目录。

备份前从程序的退出入口停止后台值守，再复制用户数据目录，以及配置中指定的外部录像、证据和模型目录。数据库运行中直接复制可能得到不一致副本。配置可能含摄像头凭据，备份应限制访问，不要提交到代码仓库或公开分享。

恢复前保留现有数据副本，核对版本与路径兼容性。先在独立位置验证，不要直接覆盖唯一的原件。仅备份程序安装目录不能代替用户数据备份。

## 卸载与数据保留

先正常退出桌面程序和后台值守，再从 Windows“已安装的应用”卸载。卸载器发现进程仍在运行时可能取消操作；请按提示从托盘或程序菜单退出后再试。

卸载默认保留用户数据，以及安装器不管理的外部模型、录像和自定义路径。因此卸载不等于删除摄像头凭据或历史记录。需要清理时先确认备份和精确路径，再自行处理；不要删除不明系统临时文件。

## 可选云端图片理解

默认不启用云端图片外发。使用云端图片理解需要显式选择提供方，填写支持图片的模型与 API 地址、设置密钥环境变量名，并明确同意发送采样图片和提示。

密钥内容应在启动程序前设置到本机相应环境变量中；向导只保存变量名，不应填写或公开密钥。服务可能按图片、输入或输出内容收费，请自行确认价格、额度、保存政策和使用地区要求。保存配置不会测试接口，也不证明模型可用或答案准确。

启用后运行时可按已保存配置发起请求，不应理解为每次请求都会另弹确认。更换提供方、地址或模型前，重新核对外发范围与费用。不要将包含凭据、私人画面或完整配置的诊断材料公开上传。

## 模型资源与许可证

不同包的模型承载范围可能不同，请核对随包模型清单、版本、摘要、硬件要求和许可说明；安装程序文件不代表全部模型已准备好。不要仅凭文件名相同替换模型或混用不兼容权重。

本地模型通常不需要云端 API，但仍消耗内存与计算资源。资源不足或模型不可用时，以界面显示的实际能力为准，不要把“正在分析”或旧记录当作本次成功结果。

程序代码、第三方代码、模型权重和数据可能分别适用不同许可证。转发安装包、模型或修改后的程序前，需确认相应通知、署名、源码和使用条件；项目自身许可证不能自动覆盖全部第三方资产。开发包可在本机运行，不代表已具备对外再分发条件。
