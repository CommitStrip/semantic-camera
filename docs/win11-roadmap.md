# Win11 值守工作站版独立路线图

> 产品入口：`python -m scam.win11`  
> 定位：有人操作的本机视频值守工作站，而不是缩小版 Linux 服务器。  
> 状态纪律：Windows CI 只证明自动化兼容，原生 Win11 实机验收单独记账。

## Win11 专属范围

- 双击启动、前台状态、浏览器工作台和可理解的故障提示；
- `%LOCALAPPDATA%\semantic-camera` 数据落点，不要求仓库目录可写；
- Windows PowerShell 5.1/7 安装链、UTF-8/GBK、中文空格路径；
- 摄像头/文件/RTSP 的交互式接入与本机模型管理；
- 前台崩溃恢复、可选任务计划程序，不依赖 systemd；
- 工作站使用时段内的8小时稳定性，以及可选24小时值守验证。

Linux 的 systemd、无头运维、Home Assistant 集成和默认长期录像不进入 Win11
发布门禁。

## 近期开发顺序

1. 用全新 Windows 用户完成安装、启动、停止和再次启动闭环；
2. 建立 Win11 首页状态与“模型缺失/流不可达/端口占用”可操作提示；
3. 完成环境识别、网格圈选、事件审查的桌面工作台闭环；
4. 增加前台看门狗和崩溃后的数据库恢复验证；
5. 完成8小时原生实机报告，再决定是否把24小时值守作为默认承诺。

## 发布准入

- `scam.win11` 是 PowerShell、BAT 和快捷方式唯一入口；
- Windows 11 非管理员用户可在中文空格路径安装运行；
- 工作台 `/api/health` 可达，关闭与重启不损坏 SQLite；
- 中文输出重定向无崩溃，模型缺失不虚假声明成功；
- 进入、持续、离开、重入、跨区五场景状态机通过；
- 8小时内存与句柄有界；24小时结论只有实测后才能写入发布说明。
