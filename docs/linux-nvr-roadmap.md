## Linux 专属范围

- systemd 生命周期、无头运行、日志和崩溃自动拉起；
- 多路 RTSP 长期连接、断流看门狗和相机健康；
- ffmpeg 分段录像、保留水位、告警片段导出；
- 反向代理或 SSH 隧道后的远程工作台；
- 24 小时以上浸泡、磁盘水位、内存和句柄平台期；
- MQTT/webhook 与 Home Assistant/Node-RED 集成。

Win11 的桌面启动器、控制台编码、任务计划程序和本机浏览器体验不进入
Linux 发布门禁。

## 近期开发顺序

1. 先落事件生命周期与单相机不可重叠审查段，告警不依赖录像成功；
2. 接入 detect/record 流角色、录像缓存与分级保留策略；
3. 加逐相机断流看门狗、运行统计和故障隔离；
4. 完成真实源时间戳到告警送达的 P50/P95/P99 度量；
5. 增加录像 replay，固定配置快照和模型哈希后复现检测链；
6. 接入两路以上 RTSP，验证录像与检测不会相互拖垮；
7. 完成 24 小时真机浸泡报告后再声明 Linux 版可发布。

## 发布准入

- `scam.linux_nvr` 是部署脚本和 systemd 唯一入口；
- 至少两路真实 RTSP 连续运行24小时；
- 断流30秒内进入恢复流程，恢复后继续形成事件；
- 告警 P95 ≤1秒，且使用真实源时间戳；
- 录像可播放、容量闸正确、数据库迁移和重启恢复有证据；
- 默认不向公网发送帧，远程工作台必须经受控入口访问。
